# Portable Wind Sensor based on MEMS Pressure Sensors

This repository contains the design files for a portable wind sensor developed in 2025/26 at the University of Applied Sciences Technikum Wien. This project was completed as part of the Bachelor's Thesis:

"Entwicklung eines tragbaren Windsensors auf Basis von MEMS-Drucksensoren"
(Development of a Portable Wind Sensor Based on MEMS Pressure Sensors)
